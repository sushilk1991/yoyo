# Threads, blind judging, and nested-call bounds

**Goal:** Let a caller invite another agent into the same conversation, the way agent-tincan rooms do, without giving up yoyo's rule that the caller is the message bus. Close the gaps the audit exposed along the way.

**Source audit:** agent-tincan (`mvanhorn/agent-tincan`, read as untrusted data, never executed), audited independently by Claude and by Codex through `yoyo ask codex --role review --read-only`, then reconciled.

## Decisions

| tincan mechanism | yoyo decision | Why |
| --- | --- | --- |
| Rooms: `@name` posts become asks, replies mirror back, mirrored replies never parsed for mentions | **Adapt** as `yoyo thread` | One explicit `ask --thread` per turn instead of mention routing; agent text never schedules a turn, which is tincan's own rule for mirrored replies |
| Pass the conversation: deterministic packing, newest turns whole first, nonce-fenced, framed as data | **Adopt** as the packer for turns and `export --format brief` | Vendor-neutral history for fresh processes, so every agent gets multi-turn context |
| Council: blind shuffled labels, peer ballots, chairman | **Adapt** the blindness into the existing judge | The judge prompt named each candidate's vendor; peer ballots and leaderboards wait until blind judging proves insufficient |
| Chains: hop limit, loop rejection | **Adapt** as `YOYO_DEPTH` / `YOYO_MAX_DEPTH` plus parent ids in the ledger | Delegates inherited no depth or parent; a caller-driven codex → claude → codex thread stays legitimate, so no loop ban |
| `--then` follow-ons | **Reject** | Removes the caller's check between agents |
| Clarification rounds | **Free** with threads | A delegate's question is a turn; the caller answers with the next ask |
| Work leases | **Reject** | Threads need a real lock (flock), not an advisory claim |
| Relay, wake methods, owner approval, phone, web agents | **Reject** | Remote delivery problems; yoyo is local, single-file, daemonless; an approval file is not a boundary against a shell-capable agent |

## Phase 0 — standalone fixes

- [x] Blind judge: shuffled letter labels, random fences, `judge_labels` to the caller only, note when the judge is a candidate.
- [x] Nested delegation: `YOYO_DEPTH`, `YOYO_PARENT_TRACE_ID`, `YOYO_PARENT_RUN_ID` in every delegate's env; refusal at the limit before spending; provenance in run meta.
- [x] Journal the normalized final answer (`answer.txt`), so codex's final message survives its scratch file and `runs show` prints it.
- [x] `sessions.json`: flock around read-modify-write, atomic replace.

## Phase 1 — threads

- [x] `thread create|invite|uninvite|note|show|list|rm`, `ask --thread`, `--history-bytes`.
- [x] Read-only turns by default, `--write` per turn; reject `--agent-arg`, `--session`, `--raw`, fan-out, `--judge`.
- [x] Turn lock for a run's duration, manifest lock for edits and id allocation, stale `running` → `interrupted`, signal flush, private atomic files, symlink and name checks.

## Phase 2 — handoff

- [x] `thread export --format md|json|brief`, `thread create --from-file` with strict validation; imported data cannot set members, cwd, permissions, models, or run ids.
- [ ] Export of a vendor's native session: needs per-vendor history readers; out of scope.
