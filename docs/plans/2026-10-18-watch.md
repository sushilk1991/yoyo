# YOYO Watch Implementation Plan

**Goal:** Browse delegated agents and their available output without controlling their processes.

**Architecture:** Read the existing ledger through private helpers in `bin/yoyo`; expose `watch` with a curses dashboard and a plain/JSON snapshot fallback. Optional Ghostty AppleScript and Herdr CLI launchers start only the viewer. Keep execution adapters unchanged in this first version: buffered providers remain visibly labelled.

**Tech stack:** Python 3.9+ standard library, existing unittest CLI harness.

## Approved design

- `yoyo watch [RUN_ID] --cwd PATH`: project-filtered run list, selected run details and bounded output tails. Up/down selects, Tab switches output stream, p toggles prompt, q detaches. No worker input or process control.
- `--once` prints a snapshot; `--json` prints a machine-readable snapshot. Non-TTY invocations print once rather than hang.
- `--open ghostty|herdr --split right|down`: open one viewer surface explicitly, preserving the effective ledger path and project. Ghostty defaults to a new window without `--split`; Herdr defaults to a new tab. No GUI automation fallback.
- Read output as untrusted text; remove terminal controls, bound tails and prompt reads, tolerate partial metadata and disappearing files. Scan beyond the display limit before filtering active runs.
- Keep prompts hidden by default. Status distinguishes running, completed, failed, dead, and unknown; completion is process completion only.

## Execution

1. Add CLI tests for snapshots, selection, filtering, unsafe output, malformed records, bounded reads, no-output cases, and mocked launcher contracts. Run them red.
2. Implement ledger readers, safe renderer, curses selection, and terminal launchers in `bin/yoyo`. Run focused tests green.
3. Add PTY coverage for keyboard detach and worker survival; test launcher failures and argument boundaries without controlling real apps.
4. Document usage and buffered-output limits in `README.md` and `docs/REFERENCE.md`.
5. Run `python3 -m py_compile bin/yoyo` and `python3 -m unittest discover -s tests`. Review the diff; do not commit or open real terminal surfaces without a separate request.

Structured Codex/Claude streaming adapters and explicit execution parent IDs remain follow-up work, not changes to existing agent invocation contracts in this version.
